# 🌌 Visionary AI Studio

A professional-grade AI image generation web application built with **Gradio** and powered by the **FLUX.1-schnell** model. This studio allows users to create stunning visuals using natural language prompts and curated art styles.

## 🚀 Live Demo
[**Click here to view the live App**]([https://3b4037c1e15a21446a.gradio.live](https://huggingface.co/spaces/hassan121ahmad/Image_generation))


## ✨ Features
- **FLUX.1-schnell Engine**: High-speed, high-fidelity image generation.
- **Style Presets**: Instantly apply Cinematic, Cyberpunk, Fantasy, Anime, and 3D Render aesthetics.
- **Modern Dark UI**: A sleek, custom-themed interface built with advanced CSS gradients.
- **Instant Downloads**: Generate and save your creations locally with one click.
- **Advanced Controls**: Fine-tune the generation process with adjustable inference steps.

## 🛠️ Tech Stack
- **Framework**: [Gradio](https://www.gradio.app/)
- **Model**: [FLUX.1-schnell](https://huggingface.co/black-forest-labs/FLUX.1-schnell) via Hugging Face Inference API
- **Backend**: Python, Requests, Pillow (PIL)
- **Frontend**: Custom CSS with Slate and Violet themes

## ⚙️ Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/visionary-ai-studio.git
   cd visionary-ai-studio
   ```

2. **Install requirements:**
   ```bash
   pip install gradio requests Pillow
   ```

3. **Set up your HF Token:**
   Make sure to set your Hugging Face token as an environment variable:
   ```bash
   export HF_TOKEN="your_huggingface_token"
   ```

4. **Run the application:**
   ```bash
   python app.py
   ```

## 🎨 Usage
1. Enter a detailed prompt in the text area.
2. Choose a pre-defined **Art Style**.
3. Click **✨ Generate Image**.
4. Use the **⬇ Download Image** button to save your artwork.
